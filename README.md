# Exp-1 ATM & BANKING SYSTEM

# AIM:
To develop an ATM and Banking System that allows users to perform basic banking operations such as checking balance, depositing money, withdrawing money, and viewing account details securely.

# SRS (Procedure):
Procedure:

Start the program.

Display the ATM and Banking System menu.

Ask the user to enter their PIN for authentication.

Display the available banking operations.

Allow the user to select an option:
    Balance Enquiry
    Cash Deposit
    Cash Withdrawal
    Account Details
    Exit

Perform the selected operation.

Update the account balance after deposit or withdrawal.

Display the transaction details and updated balance.

Repeat the process until the user selects Exit.

Stop the program.
